## 设计计划

主题是李鹏 / adfkj2 的个人工程实践：Java 后端、长期记忆与有证据的 AI Agent。读者需要快速识别身份、理解项目、找到源码，再进入可读的技术记录。

- 色彩：Graphite `#111418`、Surface `#191e25`、Chalk `#f0f2f4`、Slate `#a6b0be`、Ice `#b9d2f0`、Mint `#a0cbb8`。深色是用户明确的偏好；浅色使用清冷灰白，不借用奶油与陶土的通用组合。
- 字体：自托管 Manrope 负责英文字形与数字；中文使用本机优质系统字体。主标题探索 60–72px，正文 16px，长文 17px / 手机16px。有意义的辅助信息保持可读。
- 布局：左对齐的大标题与个人身份，右侧一幅可读的记忆概念图；主案例 D.I.V.E. 用完整横向版面，Medical QA 用独立管线叙述，研发中的两个项目用紧凑记录。让展示大小对应内容的重要性和阶段。
- 交互：响应用户操作的菜单、筛选、主题与概念图切换；不再用每个区块的上滑淡入制造统一的模板感。键盘、减少动态偏好、轻量客户端脚本继续保留。

## 写代码前的自审

最初的“工程手稿”方向容易再次变成整页编号、大写标签与单色卡片套件，因此作出以下修正：

1. 移除无顺序含义的区块编号，以及每段前都重复的全大写 eyebrow。
2. 不给标题的半句统一染蓝；层级依靠尺度、字重和自然换行。
3. Hero 与 D.I.V.E. 不再重复同一张三层 SVG。前者表达主题，后者解释工程链路。
4. 项目按主案例、次案例与研发记录分配版式，不用同一种卡片承载全部内容。
5. 空博客直接说明正式文章状态并提供有标记的示例，不用大块占位内容制造完整度。
6. 降低无内容意义的边框、标签框和装饰字符，用准确的排版与真实信息建立品质感。

保留现有 Astro、内容集合、域名、用户填写的姓名与联系方式。所有项目状态、实验边界与草稿隔离继续生效。本轮不部署、不修改服务器或 DNS、不提交或推送 Git。

## 实现与视觉验收

设计已落实到首页、项目展示、全站主题与阅读样式。自托管 Manrope 字体为24,836字节，附带字体许可；没有增加前端框架或运行时依赖。

- 主标题保留中文语义换行，姓名由集中配置读取。
- D.I.V.E. 为横向主案例，Medical QA 为独立检索管线，两个研发项目为紧凑记录。
- Hero 的形成、演化与检索可切换，说明文字以 aria-live 更新；手机采用更清晰的三段流程。
- 手机项目蓝图改为四个可读阶段，避免将桌面 SVG 小字直接缩小。
- Journal 展示真实未发布状态，删去纯装饰内容；文章示例与正式内容继续隔离。
- 阅读正文桌面17px、手机16px，手机代码12px。浅色辅助字与 skip link 对比度已修正。
- 项目筛选支持 URL 深链接和浏览器前进后退，主题与浏览器栏颜色同步。

经代码审查与独立视觉审查，未发现剩余阻止本轮交付的问题。静态产物的14种页面在5个固定宽度下均验证：1440、1024、768、390、360px，共70个唯一组合，无横向溢出，每页一个h1。每条记录包含实际读取的视口宽度，不依赖仅发送尺寸切换命令。
