## 主要项目

### D.I.V.E. · 长期记忆与本地项目助手

探索如何让跨多次交互的项目上下文延续下去：将已确认的事实、来源与版本组织为长期记忆，在需要时检索并打包为当前上下文。公开仓库中的本地助手将提案、确认执行和结果核验分开处理。

- 关注点：记忆生命周期、来源追溯、更新边界、语义检索与上下文组织。
- 当前本地助手默认使用 SQLite；PostgreSQL / pgvector 是存储与检索工程的探索方向。
- 状态：持续迭代。历史实验规模与当前默认实现分别理解，不将实验数据外推为生产性能。

[项目介绍](https://adfkj2.cloud/projects/dive/) · [源码与工程记录](https://github.com/adfkj2/D.I.V.E.Program_Sanofi)

### Medical QA Agent · 有证据的医药知识问答

围绕 Graph-Augmented RAG，将药品标签文档检索与知识图谱关系路径结合，融合和重排候选证据，再组织可追溯的回答；证据不足时明确表达边界。

- 关注点：混合检索、证据重排、来源追溯与受约束生成。
- 技术方向：RAG、知识图谱，BGE-M3 / FAISS 为可选适配。
- 状态：研究 Demo，使用小型演示数据，供检索与生成链路研究。

[项目介绍](https://adfkj2.cloud/projects/medical/) · [源码](https://github.com/adfkj2/medical-qa-agent)

## 这个网站

本站是我的项目展示与工程记录入口，使用 Astro 静态构建与 MDX 内容集合，支持深浅主题、响应式阅读、项目筛选和记忆链路交互。动效围绕首屏、记忆图与项目展示展开，可主动暂停，也尊重系统的减少动态效果偏好。

代码合入 `main` 后，GitHub Actions 自动检查、构建并通过 SSH 发布到服务器；发布健康检查失败时恢复上一版本。
